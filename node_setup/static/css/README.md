# `node_setup/static/css/` — First-run Wizard Stylesheets

Stylesheets for the server-side first-run wizard. Small on purpose — the wizard must work before any of the main-site assets are available.

Typical files: `setup.css` (layout + form controls), `progress.css` (step ribbon), `theme.css` (palette tokens).

## Conventions

- No framework, no preprocessor.
- System fonts — no webfonts (the setup is usually reached before networking is configured).
- Dark-mode-first with a light override.
- No CSS animations except the progress ribbon's single transition.
